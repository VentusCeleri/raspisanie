Пары — политика конфиденциальности

Приложение «Пары» (iOS) и сайт ventusceleri.github.io/raspisanie показывают расписание учебных занятий. Обновлено 27.11.2026.

Какие данные собираются

Никакие. Приложение не требует входа, не собирает персональные данные, не использует аналитику, рекламные идентификаторы и отслеживание.

Приложение и виджет загружают публичный файл расписания с этого сайта (GitHub Pages). Как любой веб-сервер, GitHub может технически обрабатывать IP-адрес запроса — см. политику GitHub. Выбранные подгруппа и тема хранятся только на устройстве.

Источник данных

Расписание берётся из открытого расписания РГУ нефти и газа (НИУ) имени И.М. Губкина. Приложение неофициальное и не связано с университетом; при расхождениях верным считается официальное расписание.
