Виджет «Пары»

Текущая и следующая пара с аудиторией прямо на экране телефона. Расписание обновляется само с сайта Губкина.

Нужно бесплатное приложение Scriptable — оно рисует виджет. Ставишь один раз, дальше всё обновляется само.
  1. Установи Scriptable из App Store.
    Открыть в App Store
  2. Скопируй код виджета:
    Если кнопка не сработала — выдели текст ниже целиком и скопируй.
  3. Открой Scriptable → «+» вверху справа → вставь код (долгое нажатие → «Вставить»). Нажми на название сверху и назови Пары → Done.
  4. На экране «Домой» зажми пустое место → «+» → Scriptable → выбери размер → «Добавить виджет».
  5. Зажми виджет → «Изменить виджет» → Script: Пары. Если ты во 2 подгруппе — в поле Parameter напиши 2.

Можно добавить и на экран блокировки: зажми его → «Настроить» → виджеты → Scriptable → «Пары».

Маленькое приложение «Пары» с виджетом. Не из Google Play — ставится файлом, поэтому телефон попросит разрешение.
  1. Скачай приложение:
    Скачать pary.apk
  2. Открой скачанный файл (шторка уведомлений или «Загрузки»). Если телефон скажет, что установка из этого источника запрещена, нажми «Настройки» → включи «Разрешить из этого источника» → назад → «Установить».
  3. Открой приложение «Пары» и выбери свою подгруппу.
  4. Зажми пустое место на рабочем столе → «Виджеты» → найди «Пары» → перетащи на экран. Размер можно растянуть: в большом видно весь день.

Google Play Защита может предупредить «неизвестное приложение» — это нормально для приложений не из магазина. Нажми «Всё равно установить». На Xiaomi/Huawei, если виджет перестал обновляться, разреши «Парам» автозапуск.
